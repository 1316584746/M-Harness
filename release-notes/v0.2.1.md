## 更新内容

1. **自动创建机器人**：设置里一键创建并绑定飞书机器人，不用再手动配置 lark-cli；创建后自动启动消息通道。
2. **机器人关联业务群**：机器人可以关联任务对应的需求群，并处理这个群里的相关事务：
   - 群里 @ 机器人的消息会进入对应任务的会话，带着任务上下文回答；不同群、不同任务互不串话。
   - 每个任务可以单独选择「群里 AI 的回复方式」（流式更新 / 整段回复 / 跟随全局）。
   - 回复用卡片展示进度；需要确认的操作，直接在群里点按钮批准或拒绝。
   - 支持图片、文件附件和引用消息；同一时间多条消息会排队，并告知前面还有几个。
   - Agent 在群里可以发消息、查成员、看历史记录。
3. **飞书设置调整**：飞书相关的设置页面和操作内容重新整理（机器人状态、绑定需求群的对话框、按钮状态与文案等）。

## 其他改进

- 任务页「改动」行数一律相对基线分支统计（仓库设置里配的基线 → 远端默认分支 → main / master / develop），提交与否都不会变成 0。
- 我的排期补充读取飞书项目的工时排期，不在待办里但在这段时间有排期的需求也能看到。
- 数据库查询页支持 Ctrl + S 保存查询。
